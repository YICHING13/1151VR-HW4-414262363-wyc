HW4 導演飛行器物件及UI

一、製作流程
1. 建立遊戲場景
使用 Unity 6 建立 3D 專案。
加入地板、天空及光源，完成基本的遊戲環境。
調整 Main Camera 的位置和角度，讓畫面可以清楚看到飛機及前方的障礙物。

2. 匯入飛機與隕石模型
匯入飛機模型及 Low Poly Rocks 素材。
調整飛機的大小、位置及方向。
將隕石設定成 Prefab，方便後續重複生成。
調整模型比例，避免飛機和隕石大小差太多。

3. 設定飛機移動
建立 PlayerController.cs，讓玩家可以控制飛機移動。
使用 Input.GetAxis() 偵測方向鍵或 WASD 的輸入。
設定飛機自動向前飛行，速度為 25。
上下左右的移動速度設定為 15。
限制左右移動範圍為 X = -4～4。
限制上下移動範圍為 Y = 4～14，避免飛機飛出畫面。

4. 製作隕石生成系統
建立 MeteorSpawner，負責生成隕石。
設定隕石出現的位置及生成間隔。
使用 Random.Range() 隨機決定隕石的位置。
透過 Instantiate() 生成隕石，讓飛機在前進過程中需要閃避障礙物。

5. 加入碰撞與計分功能
在飛機和隕石上加入 Collider。
利用 C# 偵測飛機是否碰到隕石。
使用 GameManager 管理分數。
設定成功通過障礙物時加分，碰撞時則觸發對應效果。

6. 加入音效
使用 Audio Source 加入三種音效：
飛機飛行時的音效
撞到隕石時的音效
成功通過障礙物時的音效
並透過程式控制音效在對應情況下播放。

7. 調整遊戲畫面與測試
調整攝影機的位置，讓飛機維持在適合的畫面範圍內。
修改飛機、隕石及地板的比例。
調整光源和背景，讓遊戲畫面更清楚。
在 Unity 中按 Play 測試飛機移動、隕石生成、碰撞及音效。

8. 輸出到 iPhone
在 Build Profiles 中切換至 iOS 平台。
將完成的遊戲場景加入 Scene List。
Build 後使用 Xcode 開啟專案。
設定 Bundle Identifier 和 Signing。
連接 iPhone，透過 Xcode 的 Run 將遊戲安裝到手機。
最後在 iPhone 上測試，確認遊戲可以正常執行。


二、相關操作
1. 飛機移動
按鍵   功能
W / ↑ 向上移動
S / ↓ 向下移動
A / ← 向左移動
D / → 向右移動
飛機會自動往前飛，玩家可以使用方向鍵或 WASD 控制飛機移動。

2. 遊戲玩法
開始遊戲後，飛機會持續向前飛行。
隕石會隨機出現在飛行路徑上。
玩家需要控制飛機上下左右移動，避開隕石。
成功通過障礙物可以獲得分數。
碰到隕石時會觸發碰撞效果及音效。

3. 遊戲測試
在 Unity 中按下 Play 開始遊戲。
使用方向鍵或 WASD 操作飛機。
測試隕石生成、碰撞偵測及音效是否正常。
最後將遊戲輸出至 iPhone 進行實機測試。
